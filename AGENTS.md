# Agent instructions for this repository

## NEVER upload secrets to this repository

This repository is **public**. Everything committed here is visible to the
whole internet, forever, including in git history after deletion.

- Never commit API keys, access tokens, passwords, private keys, cookies,
  session data, or credential files of any kind (including `.env` files).
- Never commit personal information that is not already public, private
  messages, or screenshots that happen to show any of the above.
- This repository is only for temporary, safe-to-publish files such as
  verification screenshots and working images.
- If a secret is ever committed by mistake, treat it as leaked: revoke and
  reissue the credential first, then worry about cleaning up history.
