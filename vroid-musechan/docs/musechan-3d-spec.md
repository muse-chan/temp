## 基本パラメータ

- **身長: 158cm** (設定として確定)
- 頭身: 2D 基準絵は約4頭身のデフォルメ。VRoid の素体は等身が高めなので、そのままでは再現できない。Phase 1 で「頭部を大きめ + 身長スライダーを低め」に寄せて近似し、スクリーンショットで照合しながらバランスを決める (最終判断は先輩と)
- 体型: 小柄だが胸は大きめ。ウエストは衣装で隠れる前提でも素体側で付ける
- 姿勢: 三面図は直立・ニュートラルポーズ

## 不変条件 (チェックリスト)

- [ ] ほくろは **左目の左下に1つだけ** (正面から見て左側の目の下)。顔テクスチャへの描き込みで再現し、正面レンダリングで基準絵と一致を確認する。**テクスチャの左右反転に注意**
- [ ] 水色メッシュは **2束**: 顔横の前髪脇 (正面から見て左) に1束と、ポニーテールの中に1束 (同じ色)
- [ ] 髪型は **長めの普通のポニーテール**: 頭の高い位置を黒いシュシュで1本に結び、束は背中側に垂らす (肩から前には流さない)。背中に流れる下ろし髪はない
- [ ] 目はジト目寄り (半目気味)、太めの上まつ毛ライン、瞳はティール
- [ ] 身長 158cm

## 衣装仕様 (標準衣装)

### パーカー
- 黒寄りグレーのダボダボ (オーバーサイズ)。裾は太もも中ほどまで
- フードは被らず背中に垂らす。カンガルーポケットあり、手はポケットに入れた絵が基準だが、モデルでは腕は通常位置でよい
- 袖は長めで手の甲にかかる程度

### 白キャミ (インナーとして別レイヤー)
- 白、細ストラップ、ゆったりしたシルエット。丈は短めでへそが出る (2026-11-02 変更。どこまで短くするかは 3D 制作時にスクリーンショットで決める)

### 共通の下衣・足元
- ネイビーのショーツ、白のクルーソックス、白スニーカー

## 生成した三面図の既知のズレ (モデリング時は本節を優先)

側面・背面図は生成画像のため、以下のズレがある。**基準絵 (正面) と不変条件が正**。

1. **側面図の頬の点々**: パーカー側面図にそばかす状の点があるが、誤り。ほくろは正面の1つだけ。
2. 側面図の水色の前髪束は、前髪の際と顎下の2箇所に分かれて見えるが、実際は顔の横を垂れる1本の束。
3. **真上図**: 厳密な平面図ではなく真上寄りの俯瞰図として生成されている。頭頂・シュシュ・フードの位置関係の参考として使うこと (水色の1束は左前方に正しく出ている)。

背面図・右側面図の「全体が1つの高いポニーテール」と「ポニーテールの中の水色の筋」は誤りではなく、正しい描写 (2026-11-02 訂正)。
