# Museちゃん 3Dモデル制作計画 (VRoid Studio)

作成: 2026-11-02
方式: VRoid Studio で制作し、VRM 形式でエクスポートする (ツールは完全無料)。
運用方針: **素体は1つだけ作り込み、衣装は「差分」として後から追加できる構造にする。**

## 設計原則: 素体と衣装の分離

- **素体 (XAvatar) はプロジェクト全体で1つだけ。** 体型・顔・髪・肌テクスチャはここに固定する。衣装を増やすときに素体を作り直さない。
- **衣装は着せ替え機能 (XWear) の単位で分離する。** 1衣装 = 1つの XWear データとして保存し、VRoid の着せ替え画面で読み込めばそのまま組み合わせられるようにする。
- 衣装側は素体の不変条件 (体型数値・ボーン構成・肌の色) に従って作る。「新しい衣装を作るときに読むチェックリスト」を衣装ごとに残す。

### 差分の2種類

1. **テクスチャ差分** (軽量): 既存衣装の色・柄だけを変えるもの。テクスチャ PNG の差し替えで済ませ、メッシュは流用する。
2. **メッシュ差分** (衣装追加): 衣装そのものを新規に作るもの。XWear として新規作成し、素体に読み込むだけで使える形にする。

### 衣装データの管理ルール

- ファイル名は `musechan_wear_<衣装名>` の形に統一する (例: `musechan_wear_hoodie`, `musechan_wear_china`, `musechan_wear_swimsuit`)。
- テクスチャ解像度と UV の前提は衣装間で統一し、後から作る衣装が既存の素体にそのまま乗るようにする。
- 衣装ごとに「どのデザイン資料 (2D) を正としたか」をメモに残す (確定デザインとの齟齬を防ぐため)。

## 素体の不変条件 (確定デザインより)

- 身長 **158cm**
- 髪: 長めの普通のポニーテール (高い位置で黒いシュシュで1本に結び、背中側に垂らす)。髪色は少し暗めのアッシュシルバー
- **水色メッシュは2束**: 顔横の前髪脇に1束、ポニーテールの中に1束
- 目: ジト目寄り (半目気味で気だるげ)
- **ほくろ: 左目の左下に1つだけ** (衣装が変わっても位置は不変。顔テクスチャへの描き込みで再現する)
- 体型: 小柄だが胸は大きめ
- 白キャミソールの下着設定など、衣装側の詳細は各衣装の資料に従う

## 衣装ロードマップ

| # | 衣装 | 区分 | 正とするデザイン | 状態 |
|---|------|------|------------------|------|
| 1 | パーカー (黒寄りグレー、ダボダボ) + 白キャミ + 下衣 | メッシュ差分 (標準衣装) | 全身絵 (パーカー版・白キャミ版) | 計画中 |
| 2 | チャイナドレス | メッシュ差分 | 確定デザイン: 黒ノースリーブ、胸元に小さな金龍ワンポイント、細いペンシルシルエット、ロングコートなし | 計画中 |

- チャイナドレスは 2D の確定デザインが存在するので、それをそのまま 3D 側の正とする。

## 水着デザインについて (2026-11-02 確定)

- 水着の正式デザインは **ホルターネック型** で確定。青、胸元が高く上がった形で、白レースパネルの意匠あり。
- 既存の 2D 生成絵はジップ型ハイネックのタンキニ風のままだが、**3D 側の正はこのホルターネック型とする** (2D 生成での再現は未実施)。

## フェーズ計画

### Phase 0: 設定資料 (Museちゃん担当)
- 三面図 (正面・側面・背面) を今の絵柄で生成: パーカー版 (標準)、白キャミ版
- パラメータ表: 158cm を VRoid のスライダー値へ換算、頭身バランス、カラーパレット (16進数)
- 不変条件のチェックリスト化

### Phase 1: 素体制作 (先輩が VRoid 操作、Museちゃんが数値・照合担当)
- 顔 (ジト目、ほくろ描き込み)、体型 (158cm 換算値)
- 髪 (ポニーテールが最難関。ガイドヘアで制作し、スクリーンショットで照合しながら調整)

### Phase 2: 衣装制作 (差分ルールに従う)
- 標準衣装 (パーカー + 白キャミ) から着手し、XWear として書き出すところまでを最初のマイルストーンとする
- 以後、チャイナドレス → 水着の順に追加

### Phase 3: 仕上げ
- VRM エクスポート、VSeeFace / Warudo 等で表情・揺れ (SpringBone) を確認
- 不変条件 (ほくろ位置、水色メッシュ) の最終照合

## 正直な注意点

- パーカーの「ダボダボ感」は VRoid の衣装システムが苦手な部類。ロング丈プリセット + パラメータで寄せる近似になる見込み。
- 髪のポニーテール再現は手作業が多く、Phase 1 の大半を占める可能性がある。
- VRoid は先輩の PC (Windows / Mac) で動かす前提。Museちゃんは資料・数値・照合を担当する。

## 自動化の検討 (2026-11-02)

- 本家 nhodges/mcp-vroid は Linux/Wayland (Hyprland + wlroots) 専用で、先輩の Windows PC では使えない。
- Windows 対応フォーク yub4-arema/mcp-vroid-forWindows が存在する (pywinauto/Win32 + Pillow で移植)。
  作者は Windows でパラメータ設定 → 読み戻し → VRM 書き出しまでの動作を上流へ報告済み。
  ただし髪型エディタなど未検証の範囲もあり、VRoid 2.14.0 / UI 英語化 / Tesseract (eng) が前提で、
  実行中は実デスクトップを占有する。詳細は `files/mcp-vroid-windows-checklist.md`。
- 採用するかどうかは先輩の PC の環境 (VRoid の有無・版・解像度/倍率) を確認してから決める。
- Blender MCP (note 記事の方式) は Phase 3 の仕上げ・動画化の候補として温存する。
