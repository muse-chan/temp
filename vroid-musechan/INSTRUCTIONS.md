# 指示書 — Museちゃん 3Dモデル制作（VRoid Studio 2.16.0 / mcp-vroid）

## 0. この文書について

- あなた（Claude Desktop）は、先輩（この PC の持ち主）の Windows PC 上で、MCP サーバー **mcp-vroid（2.16.0 版フォーク）** を使って VRoid Studio を操作し、キャラクター「Museちゃん」の 3D モデルを制作する担当です。
- デザインの正は本書と設定資料（`docs/musechan-3d-spec.md`）です。本書と設定資料で判断できないことは、推測で決めず、先輩に確認してください。
- 成果物は次の 3 点です。
  1. 素体（XAvatar）1 つ：プロジェクト名 `musechan_base`
  2. 標準衣装（XWear）1 着：`musechan_wear_hoodie`
  3. VRM 1.0 の書き出しファイル

## 1. 環境と前提

- Windows 10/11、VRoid Studio **公式サイト版 2.16.0**（インストール済み）。
- VRoid の UI 言語は **英語必須**（理由は §2 手順 5）。日本語 UI のまま始めないでください。
- 設定の「パフォーマンス表示（Performance Monitor）」は **オフ** のままにします。オンだと編集画面の左下に FPS 等が重なって写り、画面認識の邪魔になります。
- ディスプレイの表示倍率は 100% 推奨です。VRoid は 1 つのモニターに最大化して使います。
- このサーバーは実デスクトップを直接操作します。**作業は先輩の付き添いのもとでのみ** 行い、先輩が離席したら手を止めてください。作業中、先輩は同じ PC で他の作業をしません。

## 2. セットアップ手順（未実施の場合のみ、最初に 1 回）

1. 必要ソフトを確認します：Git、Python 3.11 以上、[uv](https://docs.astral.sh/uv/)、Tesseract OCR（英語 `eng` データ入り）。無ければ先輩に伝えてから導入してください。
2. 2.16.0 版フォークを取得します（作業フォルダは先輩と決めてください）。
   ```
   git clone https://github.com/muse-chan/mcp-vroid-forWindows-216
   cd mcp-vroid-forWindows-216
   uv sync --python 3.11
   ```
3. スモークテストを実行します。
   ```
   uv run python scripts/smoke_test.py
   ```
4. VRoid Studio の UI を英語に切り替えます（初回のみ）：ケバブメニュー `⋮` → Settings → Language → English。あわせて Performance Monitor がオフであることを設定画面で確認します。
5. Claude Desktop の MCP 設定（`mcpServers`）に登録します。`MCP_VROID_EXE` には公式サイト版の `VRoidStudio.exe` のフルパスを指定します（場所が分からなければ先輩に聞いてください。デスクトップのショートカットのプロパティで確認できます）。
   ```json
   {
     "mcpServers": {
       "vroid": {
         "command": "uv",
         "args": ["run", "--directory", "C:\\path\\to\\mcp-vroid-forWindows-216", "mcp-vroid"],
         "env": {
           "MCP_VROID_TESSERACT": "C:\\Program Files\\Tesseract-OCR\\tesseract.exe",
           "MCP_VROID_EXE": "C:\\path\\to\\VRoidStudio.exe"
         }
       }
     }
   }
   ```
6. Claude Desktop を再起動し、`vroid_status` で健全性を確認してから `vroid_launch` で起動します。

## 3. 2.16.0 の検証（本制作の前に必ず実施）

- このフォークの操作位置（アンカー）は VRoid **2.14.0** で校正されたもので、2.16.0 では未検証です。経緯と根拠はフォーク側の `docs/vroid-216.ja.md` にあります。
- 本制作に入る前に、**使い捨ての新規モデル**で受け入れ確認を順に実行してください。
  ```
  uv run python scripts/windows_acceptance.py create
  uv run python scripts/windows_acceptance.py edit
  uv run python scripts/windows_acceptance.py color
  uv run python scripts/windows_acceptance.py save
  uv run python scripts/windows_acceptance.py export10
  ```
- 全フェーズが通り、書き出されたファイルが正しい VRM 1.0 であることを確認できたら、本制作に進みます。
- 失敗した場合は、無理に進めないでください。どのフェーズで・何が見つからなかったか（OCR で読めなかったテキスト名、ずれていると思われる位置など）を記録し、先輩に報告して指示を仰いでください。座標の再測定が必要な場合は、フォーク側の `docs/ui-map.md` の形式に倣って記録してください。

## 5. 確定デザイン仕様

詳細は設定資料が正ですが、要点をここにも転記します。

### 基本パラメーター

- **身長 158cm**（確定した設定）
- 体型：小柄だが胸は大きめ。ウエストは素体側で付けます
- 頭身：2D の基準絵は約 4 頭身のデフォルメです。VRoid の素体は等身が高めなので、「頭部を大きめ＋身長を低め」で近似し、最終バランスは先輩とスクリーンショットで相談して決めます

### カラーパレット（基準絵からの採取値・目安）

| 部位 | 色 |
|---|---|
| 髪（メイン） | `#999DA5`（少し暗めのアッシュシルバー） |
| 髪（影） | `#787C84` |
| 水色メッシュ | `#38B6E8` 前後（明部は `#68BCE0` 程度） |
| 瞳 | `#63A8AD` 前後（ティール寄りの碧眼、上部に明るいハイライト） |
| 肌 | `#FAE8DE` |
| パーカー | `#4D4F53`（影 `#35373B`）、黒寄りのグレー |
| 白キャミ | `#F0F0F0` |
| ショーツ | `#384565`（ネイビー） |
| 髪留め | 黒（`#1E1E22` 前後） |
| 靴下・スニーカー | 白（`#F2F2F2` 前後） |

### 不変条件（必ず守ること）

- [ ] ほくろは **左目の左下に 1 つだけ**（正面から見て左側の目の下）。顔テクスチャへの描き込みで再現します。**テクスチャの左右反転に注意** し、描いたら必ず正面スクリーンショットで基準絵と照合してください
- [ ] 水色メッシュは **顔横の前髪脇の 1 束だけ**。ポニーテールの中や後頭部には入れません
- [ ] 髪型は **ハーフアップ**：上半分を高い位置で黒いシュシュで結び、下半分は下ろして片側の肩前に長く流します（正面絵で向かって右側の肩前）
- [ ] 目はジト目寄り（半目気味）、太めの上まつ毛ライン、瞳はティール
- [ ] 身長 158cm

### 標準衣装の仕様

- パーカー：黒寄りグレーのダボダボ（オーバーサイズ）。裾は太もも中ほどまで。フードは被らず背中に垂らします。カンガルーポケットあり。袖は長めで手の甲にかかる程度
- 白キャミ（インナーとして別レイヤー）：白、細ストラップ、ゆったり。丈は腰下まで（へそは出ません）
- 共通の下衣・足元：ネイビーのショーツ、白のクルーソックス、白スニーカー

## 6. 制作手順

### Phase 1：素体（XAvatar）

1. `vroid_new_character(base='Fem')` で新規作成します。プロジェクトは `musechan_base` として保存します。
2. **顔**（Face タブ）：パラメーターはドラッグではなく数値入力（`vroid_set_slider`）を優先します。ジト目寄りにまぶたを調整し、瞳の色は `vroid_set_color` で `#63A8AD` 前後に、上まつ毛は太めに寄せます。
3. **ほくろ**：顔テクスチャの編集で描き込みます。位置は「正面から見て左の目の左下」。テクスチャ編集画面では左右が反転して見えることがあるため、描いた直後に必ず正面スクリーンショットで照合し、逆側に出ていたら直してください。**ここが最重要チェックポイントです。**
4. **体型**（Body タブ）：身長パラメーターで 158cm 相当にします。頭身バランスは Head Size を大きめ方向＋身長低めで近似し、**スクリーンショットを先輩に見せてから確定**します（勝手に決めないでください）。胸は大きめに寄せます。
5. **髪**（Hairstyle タブ）：ハーフアップを次の構造に分けて作ります。
   - (a) 上半分を結んだ部分（高い位置、黒いシュシュ／リボン状の髪留め）
   - (b) 下半分の下ろし髪（背中に流れる）
   - (c) 片側の肩前に垂れる流れ（正面から向かって右側）
   - (d) 顔横の 1 束だけ水色メッシュ（`#38B6E8`）
   髪色はメイン `#999DA5`／影 `#787C84`。髪型エディター内の自動操作は未検証の領域です。詰まったら無理をせず、ガイドヘアのパラメーター調整でできる範囲に留めるか、先輩に手動操作を頼んでください。節目ごとにスクリーンショットで基準絵と照合します。
6. 節目ごとに `vroid_save_project` で保存を挟みます。

### Phase 2：標準衣装（XWear）

7. 標準衣装を XWear として作成し、`musechan_wear_hoodie` と名付けます。**素体（XAvatar）には手を入れません。**
8. パーカーのダボダボ感は VRoid の衣装システムが苦手な部類です。ロング丈のプリセット＋パラメーターで近似し、完全再現は狙わないでください。白キャミはインナーの別レイヤーとして作り、パーカーを脱いだ状態も再現できるようにします。下衣・足元（ショーツ、ソックス、スニーカー）も合わせます。

将来の追加衣装（今回は対象外。構造の参考に）：チャイナドレス（黒ノースリーブ、胸元に小さな金龍ワンポイント、細いペンシルシルエット、ロングコートなし。資料 `images/front-china-dress.webp`）、水着（ホルターネック型、青、胸元は高め、白レースパネル）。どちらも XWear 差分として追加し、素体は共通のまま使います。

### Phase 3：仕上げと書き出し

9. `vroid_export_vrm` で VRM 1.0 を書き出します（アバター名は `Musechan`、作者名は先輩に確認）。
10. 最終照合：正面スクリーンショットで §5 の不変条件をすべてチェックし、結果を報告します（ほくろの位置と個数、水色メッシュの場所、髪型、瞳の色）。

## 7. やってはいけないこと・注意

- `vroid_launch(restart=true)` は未保存の作業を消します。**先輩の許可なしに使わないでください。**
- VRoid Studio 以外のアプリを操作しないでください。他のウィンドウにフォーカスが移ると入力は拒否される設計です。その場合は先輩に VRoid を前面に出してもらってください。
- UI を日本語に戻さないでください。パフォーマンス表示をオンにしないでください。
- デザイン判断が割れる点（頭身バランス、髪の流れの具合など）は、スクリーンショットを先輩に見せて決めてください。推測で確定しないでください。
- ボタンやテキストが見つからないときは、同じクリックを繰り返さず、スクリーンショットを取り直して状況を確認し、報告してください。
- 保存先・ファイル名の変更は先輩に確認してからにしてください。
